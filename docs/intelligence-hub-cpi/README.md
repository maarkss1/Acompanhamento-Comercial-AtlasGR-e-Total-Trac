# ATLASGR Intelligence Hub — CPI de Construção Completa

Pacote de especificação (172 arquivos `.txt`) recebido em 2026-08-27, descrevendo a visão de
evolução da Central de Acompanhamento Comercial atual para uma plataforma corporativa de
inteligência ("AtlasGR Intelligence Hub"), cobrindo Comercial, Financeiro, Marketing, CS,
Implantação, Atendimento, TI, Produto, Inovação, Pessoas, Operações, Administrativo e Risco.

Este material é **documentação de referência / visão de produto**, não código implementado.
Ele descreve um programa de 20 sprints e 70 agentes especialistas — escopo que excede em
muito o dashboard estático atual e depende de pré-requisitos não disponíveis neste
repositório (acesso completo à API do Bitrix24, um data warehouse, pipelines de ETL, etc.).

Ponto de partida recomendado dentro do pacote: `ATLASGR_INTELLIGENCE_HUB_CPI/00_MASTER/00_LEIA_PRIMEIRO.txt`
e `ATLASGR_INTELLIGENCE_HUB_CPI/INDICE_COMPLETO.txt`.

Ao planejar a implementação de qualquer parte deste pacote, comece pelo `03_SPRINTS/SPRINT_00_DESCOBERTA_E_INVENT_RIO_TOTAL.txt`
(Descoberta e Inventário Total), conforme a seção "COMO USAR" do `00_LEIA_PRIMEIRO.txt`.
